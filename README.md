# ares-trading-bot
ARES: An automated trading bot that polls market data every 60 seconds and executes trades via the Alpaca API.

Ares v1 was made on 10/9/2026 using Claude Code through Ollama. Ares executes trades via Alpaca API. He is run on pythonanywhere.com but plans are to run him on a Raspberry Pi soon. 
He works by using by using machine learning to analyze things such as RSI, MACD, and SMA.
Ares protects the paper money by a 2% risk-per-trade limit and 5% daily stop loss
